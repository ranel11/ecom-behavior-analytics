# 🛒 eCommerce Clickstream Analytics System (SQLite & SQL)

## 📌 Описание проекта
Проект посвящен построению продуктовой аналитики на основе лога кликстрима (clickstream data) крупного интернет-магазина за ноябрь 2019 года. 

Основная цель проекта — преобразовать сырые неотсортированные данные объемного лога в оптимизированную реляционную базу данных SQLite, спроектировать витрины данных (Data Marts) и провести продуктовый анализ (воронки конверсий, Retention, LTV и поведение пользователей).

---

## 🛠 Технологический стек
* **Язык:** Python 3.x
* **СУБД:** SQLite3
* **Библиотеки:** Pandas, time, sqlite3
* **Оптимизация:** B-Tree индексирование, пакетная загрузка (Chunking)

---

## 📊 Описание сырой таблицы (`events`)
Сырые данные представляют собой файл CSV объемом **67+ миллионов строк**, содержащий информацию о действиях пользователей на сайте.

### Структура колонок:
| Колонка | Тип данных | Описание |
| :--- | :--- | :--- |
| `event_time` | DATETIME | Дата и время события (UTC) |
| `event_type` | TEXT | Тип действия: `view` (просмотр), `cart` (в корзину), `purchase` (покупка) |
| `product_id` | INT | Уникальный ID товара |
| `category_id` | BIGINT | Уникальный ID категории |
| `category_code` | TEXT | Текстовая категория (например, `electronics.smartphone`) |
| `brand` | TEXT | Бренд товара |
| `price` | REAL | Цена товара в $ |
| `user_id` | INT | Уникальный ID пользователя |
| `user_session` | TEXT | Уникальный UUID сессии |

---

## 🏗 Архитектура данных
```text
[ Сырой CSV-файл (8 GB) ]
         │
         ▼ (Chunking via Pandas)
[ SQLite: events (67M+ строк) ]
         │
         ▼ (B-Tree Индексы: user_id, user_session, event_type, event_time)
 ┌───────┼────────────────┐
 │       │                │
 ▼       ▼                ▼
[ dim_sessions ]   [ dim_users ]   [ dim_products ]
 (Воронка/Сессии)   (LTV/Профили)   (Справочник)
```

## 📝 Дорожная карта проекта (Roadmap / Tasks)
✅ Этап 1: ETL и Оптимизация БД

✅ Настройка пакетного импорта CSV-файла (67M+ строк) в SQLite через Pandas chunks.

✅ Создание структуры таблицы events с валидацией типов данных.

✅ Проектирование и генерация 4 B-Tree индексов (idx_events_user_id, idx_events_user_session, idx_events_type, idx_events_time) для ускорения SQL-запросов.

⏳ Этап 2: Проектирование витрин данных (Data Marts)

🟩 Сборка витрины dim_sessions (агрегация по сессиям, расчет флагов has_view, has_cart, has_purchase).

🟩 Сборка витрины dim_users (профили пользователей, дата первого захода, LTV, сегментация).

🟩 Сборка витрины dim_products (справочник товаров, агрегация просмотров и покупок).

⏳ Этап 3: Продуктовая аналитика и SQL-исследования

🟩 Расчет продуктовой воронки (View → Cart → Purchase) и поиск точек отвала (Drop-off rate).

🟩 Анализ времени принятия решения о покупке (Time-to-Purchase).

🟩 Когортный анализ и оценка возвращаемости (Retention Rate).

🟩 Анализ брендов и категорий (Матрица популярности vs конверсии).

⏳ Этап 4: Визуализация и Выводы

🟩 Построение графиков воронок и когорт.

🟩 Формулирование продуктовых гипотез и рекомендаций для бизнеса.
